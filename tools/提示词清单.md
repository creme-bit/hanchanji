# 寒蝉记 · 360° 全景机位提示词清单

## 怎么补图

1. 在项目根目录（index.html 所在文件夹）打开终端：`pip3 install requests pillow`
2. 一键批量生成：`python3 tools/gen_panoramas.py`（默认 Pollinations，免费不要 Token；跑完自动压成 WebP 放进 `assets/panoramas/`）
   - 只重做某几张：`python3 tools/gen_panoramas.py --only shufang-1,qianting-2`
   - 用 Hugging Face（FLUX.1-schnell，免费 Token）：`HF_TOKEN=hf_xxx python3 tools/gen_panoramas.py --provider hf`
   - 也可以把下面的提示词复制到任意生图工具（Midjourney 用 `--ar 2:1`，Blockade Labs Skybox 直接出 360 图），存成对应文件名即可。
3. 刷新网页。换了 AI 图以后画面里东西的位置变了：打开画面左下角「调试」开关，点画面上门口/地面/证物的位置，坐标自动复制，贴回 `3d/nodes.js` 对应机位的 `at: [...]`。
   - 移动圆环（links）点在**地面**上；证物（spots）点在物件本身上。
   - 小地图的朝向：AI 图的正东不一定在图的最左边，可以给机位填 `rot`（度）校正。
4. 上线前把 `3d/pano.js` 第一行附近的 `DEBUG_UI = true` 改成 `false`，调试开关就不显示（网址加 `?debug=1` 仍能临时打开）。

> 说明：剧情是腊月廿三夜里。统一风格按要求用的是「阴天潮湿自然光」；想要夜景，把每条里的 `overcast gloomy daylight` 换成 `dim night interior lit by oil lamps and cold moonlight through windows` 即可。

## 提示词

共 33 个机位。每张图：2:1 等距柱状投影（建议 2048×1024 或 4096×2048），存成 `assets/panoramas/<机位ID>.webp`（1MB 左右）。

**统一负面提示词**（支持 negative prompt 的工具都填这条）：

```
fisheye seam, visible stitching seam, tilted horizon, cartoon, anime, illustration, 3d render, oversaturated, warm orange cast, modern furniture, electric appliances, plastic, text, watermark, logo, blurry, low resolution, gore, blood splatter
```
